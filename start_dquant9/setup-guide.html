1

Make.com 설정

1-1. Make.com 무료 계정 생성

1. make.com 접속 → Get started free 클릭

2. 이메일로 회원가입 (구글 계정 연동 가능)

3. 무료 플랜 선택 — 신용카드 불필요

💡 무료 플랜: 월 1,000 오퍼레이션 무료. 9명 × 월 4회 발송 = 36 오퍼레이션으로 충분합니다.

1-2. 새 시나리오 생성 & Webhook 트리거 추가

1. 좌측 메뉴 Scenarios → + Create a new scenario

2. 시나리오 이름: DQuant9 카카오 알림

3. 첫 번째 모듈 클릭 → 검색창에 Webhooks 입력 → 선택

4. Custom Webhook 선택 → Add 클릭

5. Webhook 이름 입력: DQuant9Notify → Save

6. 생성된 URL 복사 → admin-notify.html에 붙여넣기

⚠️ URL 예시: https://hook.eu1.make.com/abc123xyz789

1-3. Make.com 시나리오 구조

아래와 같이 모듈을 구성하세요:

⚡
Webhooks → Custom Webhook

웹앱에서 POST 요청 수신 (트리거)

🔀
Router (선택 사항)

type 필드로 분기: report / monthly / custom

🌐
HTTP → Make a request

카카오 알림톡 API POST 요청

📝
Webhooks → Webhook response (선택)

성공/실패 응답 반환

1-4. HTTP 모듈 설정 (카카오 API 연결)

HTTP 모듈 설정값:

// HTTP → Make a request 모듈 설정 URL: https://alimtalk-api.kakao.com/v2/sender/send Method: POST Headers: Authorization: KakaoAK {발신프로필_API_KEY} Content-Type: application/json Body (JSON): { "senderKey": "{발신프로필_KEY}", "templateCode": "{승인된_템플릿_코드}", "recipientList": [ { "recipientNo": {{1.to_phone}}, "templateParameter": { "name": {{1.to_name}}, "message": {{1.message}} } } ] }
💡 {{1.to_phone}}은 Make.com의 Webhook 수신 데이터 매핑 표현식입니다. 1은 첫 번째 모듈(Webhook) 번호입니다.
2

카카오 비즈 채널 & 알림톡 설정

2-1. 카카오 비즈 채널 개설

1. business.kakao.com → 채널 관리자 센터

2. 새 채널 만들기 → 채널명: 디퀀트나인

3. 카테고리: 금융 > 투자/자산관리

4. 채널 개설 완료 (즉시 승인)

✅ 채널 개설 자체는 무료입니다.

2-2. BizMessage (알림톡) 서비스 신청

1. 채널 관리자 센터 → 알림톡 관리 → 발신 프로필 신청

2. 사업자등록증 업로드 (개인사업자 가능)

3. 심사 완료 후 발신 프로필 키(senderKey) 발급 (1~3 영업일)

4. 카카오 비즈니스 API 키 발급 (REST API 키)

⚠️ 개인 사업자도 신청 가능합니다. 심사 기간 동안 Make.com 연결까지 모두 준비해 두세요.

2-3. 알림톡 템플릿 등록 & 심사

템플릿 예시 (3일 성과 리포트):

[D.Quant 9.0 V.I.E] 3일 성과 리포트 #{이름}님의 포트폴리오 현황 수익률: +#{수익률}% 누적 수익(KRW): +#{수익KRW}원 누적 수익(USDT): +#{수익USDT} USDT 📈 리포트 전체 보기 👉 start.dquant9.com/reports.html

심사 주의 사항:

• 투자 수익률 관련 내용은 가상 시뮬레이션임을 명시해야 심사 통과 확률이 높습니다.
• "#{변수명}" 형식으로 치환 변수를 표시합니다.
• 외부 URL은 실제 운영 도메인(start.dquant9.com)으로 작성하세요.
• 심사 기간: 보통 1~3 영업일

웹훅 데이터 구조 (참고)

D.Quant 9.0 웹앱이 Make.com으로 전송하는 JSON 데이터 구조:

{ "app_name": "D.Quant 9.0 V.I.E", "sender_name": "디퀀트나인", "to_name": "홍길동", // 수신자 이름 "to_phone": "01012345678", // 하이픈 제거된 전화번호 "type": "report", // report|monthly|consult|custom "message": "[D.Quant...] 완성된 메시지 전문", "variables": { "name": "홍길동", "profit_rate": "10.50", "profit_won": "3,150,000", "profit_usdt": "2333.33" }, "sent_at": "2026-03-25T09:00:00.000Z", "source": "dquant9-vie-webapp" }
💡 Make.com에서 {{1.message}}로 완성된 메시지를 그대로 카카오 API에 전달하거나, {{1.variables.name}}으로 개별 변수를 템플릿에 매핑할 수 있습니다.
